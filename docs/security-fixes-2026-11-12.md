## 认证与密码轮换

账户认证现在返回实际用于 Argon2 校验的账户快照及 revision，会话只绑定这一版本。密码轮换发生在校验期间时，旧密码请求即使校验通过，也只能获得旧版本会话，后续管理请求会被拒绝；不会再用随后读取的新 revision 升级旧密码的授权。

新增账户版本证明和并发登录回归测试；修改真实管理员密码不是验证步骤。

## 反向代理的限流 IP

默认只使用 TCP 连接来源 IP。需要上层代理区分客户端时，设置：

```text
LIGHT_RATE_LIMIT_IP_HEADER=X-Light-Client-IP
```

也可使用启动参数 `-rate-limit-ip-header X-Light-Client-IP`，参数优先于环境变量。Compose 已提供同名环境变量透传；没有设置时保持禁用。

启用后，指定 Header 必须只有一个合法的 IPv4/IPv6 值，限流和审计使用规范化后的地址。Header 缺失、为空、格式错误、包含逗号链、端口、IPv6 zone 或多个字段值时，回退 RemoteAddr；不会自动信任 X-Forwarded-For、X-Real-IP。

上层反代必须覆盖客户端传入的同名字段，并限制客户端不能直接访问已启用此信任的后端。例如 Nginx：

```nginx
proxy_set_header X-Light-Client-IP $remote_addr;
```

这个 Header 是显式配置的代理信任来源，不是凭名称保密就可信的凭据。新回归覆盖启用/禁用、IPv4/IPv6/映射地址、非法值与多个客户端独立额度；认证接口原有独立频率限制和密码校验并发预算继续有效。

## 上传内容与回收

删除/GC 共用 24 小时的保护窗口，覆盖“blob 已上传、manifest 尚未发布”的间隙：

- 新写入 blob 的实际修改时间在窗口内时，不回收它的全局文件或 layer 链接。
- 机器人携带对应仓库 push scope 执行 blob HEAD、跨仓库 mount、上传完成请求前，为目标 digest 持久化租约，保护复用的旧 layer。仅 pull scope 和匿名拉取不会续租。
- 记录保存于数据卷 `jobs/upload-leases.json`，上限 32768 个未过期摘要；按摘要合并，使用原有有界、原子 JSON 写入，不增加数据库。满额时拒绝新增租约对应操作。
- 租约写入失败时，相关完成/复用操作返回 503，回收暂停；记录损坏时拒绝启动，防止在保护状态不明确时继续删除。
- 首次在已有数据上启用记录时，保守保护现有内容 24 小时。迁移截止时间持久化，后续重启不会不断延长。

行为变化：tag 删除仍立即生效；无引用但处于上传保护期的内容不会立即释放，保护期结束后通过存储维护回收。预览只统计当前确实可回收的文件。超过最后一次上传/复用检查 24 小时仍未发布的内容不再保证保留，长时间暂停的推送应重新检查/推送。此策略为有限保护窗口，不声称提供无限期的推送事务保留。

已验证新仓库待发布内容、同仓库旧 layer 复用、跨仓库 mount、GC、过期后回收、租约重启恢复、迁移期限不延长、持久化失败以及只读请求不续租。既有“无引用立即回收”测试显式使用成熟内容模型；保护期行为由使用生产默认窗口的独立测试覆盖。

## 公开查询资源预算

先枚举标签/摘要进行过滤和分页，再加载当前页至多 20 个镜像的大小和创建时间。保留按 tag 和 digest 搜索、排序及每次请求内的同摘要复用。

匿名公开 API 增加每来源 IP/路径 60 次/分钟、全局最多 4 个同时计算的请求及 15 秒计算预算。公开性授权仍实时查询事实管理数据，不依赖派生缓存。健康检查、管理登录、机器人令牌接口不占用公开查询并发槽。

原先 25 个不同摘要的标签、筛选结果 1 条时需要 75 次 blob 正文流读取，修复后为 3 次；第二页 5 条对应 15 次，不会再读取第一页的镜像正文。
